# qwuiktools
(pronounced quick-tools)

is a small website with simple tools.

## tools
### tempo tester
shows 8 different tempos:
- 1
- 1/2
- 1/4
- 1/8
- 1/16
- 1/32
- 1/64
- 1/128
and lets you control the speed of these tempos (all at once, not individually sadly) with buttons at the bottom!

### counter
lets you count with different controls (click buttons, keybinds, directly changing the input field's text) while also showing you some facts!

<details>
    <summary>facts</summary>
    most examples use 6
    whether the number is prime or not (e.g. 6 -> no) <br>
    whether the number is even or not (e.g. 6 -> yes) <br>
    the number's factors (e.g. 6 -> 1, 2, 3, 6) <br> 
    factorial of the number (e.g. 6 -> 720) <br>
    the number's square (e.g. 6 -> 36) <br>
    the number's cube (e.g. 6 -> 216) <br>
</details>
<details>
    <summary>facts (for nerds section)</summary>
    whether the number is perfect or not (e.g. 6 -> yes, 7 -> deficient, 12 -> abundant) <br>
    the number backwards (e.g. 122 -> 221) <br>
    whether the number is a palindrome or not (e.g. 121 -> yes) <br>
    the number in binary (e.g. 6 -> 110) <br>
    the number in hexadecimal (e.g. 255 -> ff) <br>
</details>

### random rumbles
generates a random number from 1 to 2^31 - 1 (2147483647) every [interval]ms!

you can control the interval via slider or by directly editing the input field.

there are also presets:

- 1 - 1000ms
- 1/2 - 500ms
- 1/4 - 250ms
- 1/8 - 125ms
- 1/16 - 62.5ms
- 1/32 - 31.25ms

### rainbow
simplest tool yet. 

shows a little box whose colour changes every 1000ms (1s)!
